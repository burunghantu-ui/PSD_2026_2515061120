# Administrasi Klinik
## Deskripsi Singkat
Program ini merupakan program sederhana untuk mendata pasien berdasarkan umur, dimana pasien di bawah 50 tahun dan lansia di atas 60 tahun akan di prioritaskan berdasarkan seberapa jauh jarak umur dari batasan yang telah ditetapkan tersebut, jika ada kesamaan jarak umur pasien dari ketentuan maka akan diurutkan berdasarkan urutan input, sedangkan pasien umur 50-60 akan ditempatkan diakhir dan diurutkann sesuai urutan angka dari 50-60.

Program ini menggunkan metode sorting selection yang menggunakan elemen acuan sebagai pembanding dengan elemen lain, sehingga cocok dengan kebutuhan program.
